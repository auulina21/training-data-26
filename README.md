# Приклад виконання практичної роботи №4 «Функціональне програмування в Java» з дисципліни "Програмування мовою Java"

Приклад об'єднує програми практичних робіт №2 і №3: цикли, методи `Collections.sort()`,
`Collections.min()`, `Collections.max()` і `Arrays.sort()` у них замінено лямбда-виразами,
посиланнями на методи й операціями Stream API. Результати операцій залишилися тими самими.
